# Deploy your node — index

Source: https://docs.n8n.io/connect/create-nodes/deploy-your-node.md

Two ways to share a finished node:
1. **Community node repository** — publicly installable, and the **only** way
   to use a custom node on n8n Cloud. See [16-submit-community.md](16-submit-community.md).
2. **Private install** — self-hosted only, no npm publish required. See
   [17-install-private.md](17-install-private.md).
